# UniMate — Student Life Dashboard

**Software Engineering HW3**  
林小蓮 111210552 資工四

UniMate is a lightweight student life dashboard that combines several everyday tools in one place. It was created to solve a simple problem: students often manage assignments, study sessions, expenses, and quick notes across different apps or forget them completely.

## Project Value

The main value of UniMate is **user value**. As a university student, I can use the project myself to organize daily academic and personal activities. Other students with similar needs can also use it without creating an account or installing software.

## Features

- Task and deadline manager
- Task completion tracking
- Pomodoro focus timer
- Daily study-time counter
- Student expense tracker
- Quick notes and longer notes
- Browser `localStorage` persistence
- Responsive dashboard for desktop and mobile

## Technology

This project uses only **HTML, CSS, and JavaScript**. No backend or external database is required. User data is stored locally in the browser using `localStorage`.

## How to Use

Open `index.html` in a browser, or visit the deployed GitHub Pages site. Add tasks and expenses, start a focus session, or save notes. The data remains available after refreshing the page on the same browser.

## Files

- `index.html` — page structure and dashboard interface
- `style.css` — responsive visual design
- `script.js` — application logic and local data storage
