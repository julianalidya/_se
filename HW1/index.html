jcurl

林小蓮 · 111210552 · 資工四

A small curl-like HTTP/1.1 client built from the networking layer upward with Python sockets and TLS—without a high-level HTTP client library.

Raw TCPConnects using Python's socket module.
HTTPS / TLSWraps TCP with an SSL context and verifies certificates.
HTTP ParsingBuilds requests and parses status, headers and body.
Streaming DetailsHandles chunked transfer and gzip responses.

Request lifecycle

URL → DNS → TCP → TLS (HTTPS) → HTTP request bytes → response stream → parsing → output

The implementation exposes the layers normally hidden by libraries such as requests or fetch. HTTP/1.1 messages are assembled manually, including CRLF boundaries and standard request headers.

Try it

# Basic GET
python jcurl.py https://example.com

# Include response headers
python jcurl.py -i https://example.com

# Inspect connection and request
python jcurl.py -v https://example.com

# POST JSON
python jcurl.py -X POST \
  -H "Content-Type: application/json" \
  -d '{"name":"Juli"}' \
  https://httpbin.org/post

Inside the implementation

GET / HTTP/1.1\r\n
Host: example.com\r\n
User-Agent: jcurl/1.0\r\n
Accept: */*\r\n
Accept-Encoding: gzip\r\n
Connection: close\r\n
\r\n

For HTTPS, the TCP socket is wrapped with TLS before these bytes are sent. The response is collected as bytes, separated into headers and body, then decoded according to response headers.

Chunked transfer decoding

When a server uses Transfer-Encoding: chunked, each body segment starts with a hexadecimal length. jcurl parses each size, copies exactly that many bytes, and stops at the zero-size terminating chunk.

5\r\n
hello\r\n
6\r\n
 world\r\n
0\r\n
\r\n

Testing

python -m unittest -v

The included tests cover request construction, normal response parsing, and chunked-body reconstruction without depending on an external server.

Scope

jcurl is an educational HTTP/1.1 client rather than a full replacement for curl. Features such as HTTP/2, HTTP/3, redirects, proxying, cookie management, multipart uploads, and authentication helpers are intentionally outside this first version.
