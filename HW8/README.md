## 專案目的與使用價值

UniMate 將作業期限、專注學習、生活支出及筆記整合於同一個網頁，協助學生管理日常生活。學生不需要註冊或安裝套件，即可開始使用。本專案的主要價值是「使用價值」：我自己及其他學生都能透過此工具整理待辦事項與學習紀錄。

## 執行方式

1. 將壓縮檔解壓縮。
2. 保持 `index.html`、`style.css`、`script.js` 在同一個資料夾。
3. 使用 Chrome 或 Edge 開啟 **index.html**。

也可將三個程式檔部署至 GitHub Pages。不需要 Node.js、npm 或後端伺服器。

## 操作方式

- **Tasks：** 新增作業、選擇期限與分類；使用搜尋及篩選找到任務。按 Edit 修改名稱與期限，勾選代表完成，× 代表刪除。
- **Focus：** 開始、暫停或重設 25 分鐘專注計時；完整完成一次才增加 25 分鐘。重新整理會重設未完成的計時。
- **Expenses：** 新增支出名稱、正整數金額及分類，首頁顯示全部支出的合計。
- **Notes：** 輸入內容即自動儲存，也可按 Save notes。
- **Download backup：** 匯出目前資料。**Restore backup：** 選擇備份檔並確認取代目前資料。
- **Reset demo data：** 確認後將目前資料重設為示範內容，建議先下載備份。

## 技術與資料限制

使用 HTML、CSS、原生 JavaScript 及 localStorage。無外部套件或網路 API。資料只存在目前瀏覽器與網站來源，沒有帳號或跨裝置同步。移至 HW8 網址或由本機切換至 GitHub Pages，不會自動帶入 HW3 網址的資料。清除瀏覽器資料可能導致紀錄消失，請定期下載備份。首次開啟包含可重設的示範資料。

## 驗證

已執行 JavaScript 語法檢查，並透過模擬 DOM／localStorage 驗證初始載入、任務完成、搜尋、刪除、每日學習歸零、空白支出拒絕、備份結構驗證與儲存。這些檢查不等同於實際瀏覽器操作或視覺測試。

瀏覽器操作檢查：新增任務 → 搜尋 → Edit → 勾選完成 → 切換 Completed；新增支出 → 重新整理確認資料；下載備份 → 修改資料 → 還原備份；測試 Focus 的開始、暫停及重設。
